# Viva's Cafe - Static Website

A responsive, modular static website template for **Viva's Cafe**, built using standard HTML5, CSS3, and modern Vanilla JavaScript.

## 📂 Project Structure

```text
vivas-cafe/
├── index.html              # Homepage
├── menu.html               # Menu page with category filters
├── about.html              # Brand story & background
├── contact.html            # Reservation form & contact info
├── assets/
│   ├── css/
│   │   └── styles.css      # Core styles & layout system
│   └── js/
│       ├── main.js         # Mobile nav & form handling
│       └── menu-data.js    # Filterable menu logic & data
└── README.md
```

## 🚀 Getting Started

1. Extract the `vivas-cafe.zip` file.
2. Open `index.html` in any modern web browser.
3. No server or build tools required!
